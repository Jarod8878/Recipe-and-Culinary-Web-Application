A web application developed using XAMPP, PHP, and phpMyAdmin to manage the database.
Key Features include
1. Recipe Management Module - create, view, edit, delete recipes
2. Meal Planning Module - Create and plan meals, and create schedules to track meals
3. Community Engagement Module - Create posts and interact with posts from other users, rate recipes posted by others
4. Cooking Competition Module - Participate in competition with recipes uploaded, vote recipes

To use this project locally:
1. Install XAMPP
2. Clone the repository
3. Move project folder into XAMPP htdocs directory
4. Start APACHE and MySQL in XAMPP control panel
5. Create database
6. Open project in browser
